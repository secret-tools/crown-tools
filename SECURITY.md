# Signaler un probleme de securite

Sur le depot GitHub officiel, utilisez le signalement prive de vulnerabilite s'il est active. A defaut, ouvrez une issue demandant un canal prive, sans publier de secrets, de donnees personnelles ni de details d'exploitation.

Indiquez la version du projet, la version de Python, Windows et les etapes minimales de reproduction sur un environnement autorise.

## Perimetre

L'application et son chargeur de packs sont dans le perimetre du projet. Les scripts tiers importes ne sont pas fournis avec la distribution et doivent faire l'objet d'une revue distincte. Leur execution n'est pas isolee du compte Windows.

Ne joignez jamais de tokens, mots de passe, profils personnels ou donnees appartenant a des tiers a une issue publique.
